# 六爻排盤

> 寫下想問的事，擲錢起卦，看白話結論、關鍵日與完整排盤。

六爻占卜的網頁版。單一 HTML 檔，無後端、無建置步驟；排盤資料與引擎都內嵌在檔案裡。

---

## 功能

| 能力 | 說明 |
|---|---|
| **問事** | 寫下所問；選主題（事業工作、財運投資、感情姻緣〔可選男／女／不指定〕、考試學業、身體健康、家人長輩、子女晚輩、人際合作、整體運勢）；可改占日 |
| **水月擲錢** | 按住印章或搖手機：龜殼搖錢、拋入水盆、化爻。銅錢走物理模擬，正反仍由隨機數決定 |
| **自動擲卦** | 一鍵擲完六次（約 9 秒） |
| **報數起卦** | 三數起卦：上卦／下卦／動爻（除 8／除 6 取餘） |
| **斷卦** | 以用神為核心，依月建、日辰、動變、伏藏、旬空等計分，給五級吉凶（上上～中下）與理由，並推關鍵日 |
| **排盤** | 本卦／變卦、宮位、世應、納甲、六親、六神、旬空、月破、伏神 |
| **解讀** | 卦辭／象曰／爻辭與白話；乾／坤六爻全動的用九／用六 |
| **卦簿** | 起卦即存（瀏覽器 localStorage，最多 60 筆）；可還原、換主題重斷、刪除 |
| **籤卡** | 產生籤卡圖，可存圖或分享 |
| **其他** | 深色模式、減少動態、鍵盤與讀屏支援 |

## 專案結構

```
6yao/
├── index.html          # 網頁版：單檔（HTML／CSS／JS／資料一體，約 260KB／3,483 行）
└── docs/superpowers/
    ├── specs/          # 設計文件（2026-08～09，v1 時期）
    └── plans/          # 實作計畫
```

`index.html` 內有五段 script：

| 段 | 全域名 | 內容 |
|---|---|---|
| 資料 | `YAO_DATA` | 八卦、64 卦宮位世應、卦爻辭、白話 |
| 引擎 | `YaoEngine` | 曆法、排盤、伏神、斷卦；純函式，無 DOM 依賴 |
| 物理 | `CoinSim` | 銅錢在空中、入水、水中、落底的模擬 |
| 畫面 | `Pond` | 水盆、龜殼、化爻、音效 |
| App | — | 流程、卦簿、搖手機、籤卡、主題 |

## 快速開始

```bash
open index.html
# 或
python3 -m http.server 8000   # 再開 http://localhost:8000
```

- 依賴：無（字型由 Google Fonts 載入：LXGW WenKai TC、Noto Serif TC）
- 「搖手機」按鈕只在觸控裝置上出現，且要在 HTTPS 網站上才收得到動作感測；iOS Safari 會在第一次按下時詢問權限

## 技術說明

- **曆法**：日柱以 JDN 推算；年柱、月柱以太陽視黃經（Meeus 低精度公式）定節氣，立春換年、交節換月。
- **排盤**：納甲裝卦；六親依本卦宮五行（變爻亦同）；六神依日干起；旬空依日柱旬首；用神不上卦時，取本宮首卦同位之爻為伏神。
- **斷卦**（`YaoEngine.judge`）：月建旺衰與月破、日辰生剋沖、動爻化回頭生剋與進退、原神忌神、伏藏、旬空（動不為空）各自加減分，對應五級吉凶與關鍵日。
- **擲錢**：每枚錢預先整段模擬，以 240 Hz 取樣播放；若落定的面與隨機結果不合，就把整段姿態繞錢身翻 180°，軌跡不變、兩面互換。
