# 籤文書籤卡片 — 設計文件

日期：2026-08-20
狀態：已與使用者確認（A 款直式書籤、彈窗自動顯示、關閉後留縮小卡）

## 目標

起卦完成後自動彈出「籤文書籤」視窗，呈現本次卦象的籤文（卦名、卦象、吉凶分級、文言原文、白話籤文），關閉後在解讀區底部保留縮小版書籤，可再點開。

## 版面（直式書籤，A 款）

由上而下：
1. 繫孔（圓孔）＋ 金朱漸層穗帶
2. 大楷書卦名（如「地山謙」）
3. 吉凶朱印（雙線框、朱砂色、四級：上上／上吉／中吉／中平）
4. 卦象爻畫（墨條，陽 46px／陰兩段 19px，自下而上排列）
5. 文言原文（卦辭＋動爻爻辭，楷體、上下分隔線）
6. 白話籤文（細字、墨灰）
7. 頁腳「六爻排盤」（小字、寬字距）

紙底宣紙（`--paper2`＋紙紋），墨色文字，朱砂點綴，維持「文人書齋·宣紙朱砂」風格。

## 互動

- 六爻擲完、排盤＋解讀渲染後，自動彈出遮罩視窗（墨色半透明＋毛玻璃），卡片 fadeUp＋stampIn 入場。
- 右上角 ✕ 鈕或點擊遮罩關閉。
- 關閉後，解讀區底部顯示縮小版書籤 chip（含卦名＋分級），點擊重新彈出（內容沿用當次起卦）。
- 退一爻／重新起卦清空結果時，chip 一併清除。
- 報數起卦（castBtn）同樣觸發書籤彈窗。
- 彈窗出現時不鎖定捲動，遮罩捲動穿透可接受（簡化取捨）。

## 吉凶分級邏輯（computeGrade）

以用神（yongshenSel：世爻或六親）為主，日辰（dayZhi 地支五行）為輔：

- 用神爻旬空 → 中平（事未定，宜守）
- 用神為動爻且不空 → 上上
- 用神得日辰生扶（日辰生用神或比和）→ 上吉
- 用神受日辰剋 → 中平
- 無動爻 → 中吉（平穩）
- 其餘 → 中吉

規則：五行生剋（木→火→土→金→水→木；剋：木→土→水→火→金→木）；地支五行映射（子亥水、寅卯木、巳午火、申酉金、辰戌丑未土）。用神爻選取：選「世爻」→ `hg.shi`；選六親 → 對應 `hg.liuqin` 首個相符爻；無相符 → 退回世爻。

回傳：`{ grade, label }`，label 為「上上／上吉／中吉／中平」。
